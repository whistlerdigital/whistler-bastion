# Bastion — AI Agent Safety Guard

Bastion is a local safety checkpoint for risky developer and AI coding agent operations, designed and maintained by [Whistler Digital](https://whistler.com.tr/open-source/bastion).

Use the Command Palette to:

- **Bastion: Evaluate Risky Operation** — inspect a shell, Git, database or automation command before execution.
- **Bastion: Initialize Project** — create safe project defaults without replacing existing configuration.
- **Bastion: Run Diagnostics** — inspect the current workspace integration and show a readable report.

Evaluation runs locally. The extension does not send commands, paths, source code or project data to Whistler Digital or another external service.

For CLI, JavaScript SDK, MCP setup, supported AI clients, security boundaries and source code, visit the [Bastion project page](https://whistler.com.tr/open-source/bastion) or [GitHub repository](https://github.com/whistlerdigital/whistler-bastion).
